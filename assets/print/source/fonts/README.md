# Print-pack fonts (SIL Open Font License)

Latin static TTF subsets, vendored so a `file://` render has no network
dependency and Chrome can subset them as Type0 CID fonts.

| Family | Files | Upstream |
|---|---|---|
| Cormorant Garamond | 400/500/600/700 roman + 400/500/600 italic | [google/fonts OFL](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond) via fontsource latin subset |
| IM Fell English | 400 roman + italic | [google/fonts OFL](https://github.com/google/fonts/tree/main/ofl/imfellenglish) |
| JetBrains Mono | 400/500 | [JetBrains Mono OFL](https://github.com/JetBrains/JetBrainsMono) |

These files are not the game; they are the typefaces the print pack embeds.
See each upstream OFL.txt for the license text.
